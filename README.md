# damou.co

Source for my personal site. Live at **[damou.co](https://damou.co)**.

Built with Next.js, Tailwind v4, and Markdown. Posts and projects are plain
`.md` files in `content/`. YouTube videos are pulled live from the channel
RSS feed and merged into the content feed.
